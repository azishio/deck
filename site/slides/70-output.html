Presenter View

Current and next slide, speaker notes, timer, clock, blackout and live diagnostics — synchronised over a websocket.

Printing

The print view loads every slide, drives it to the requested step, waits for fonts and images, then enables the button. One slide, one page.

Static build

deck build emits a folder any static host can serve. This deck is that output, on GitHub Pages.
